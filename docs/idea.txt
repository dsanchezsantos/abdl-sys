Projeto Starter Kit de Desenvolvimento de Arraial do Cabo

Este projeto estabelece o padrão oficial de engenharia de software para os novos sistemas da Prefeitura Municipal. Trata-se de um boilerplate robusto e moderno, desenhado para garantir padronização, agilidade no início de novos projetos e facilidade de manutenção a longo prazo. A base tecnológica é um monólito modular utilizando Laravel 12 (PHP 8.5) no backend e React 19 via Inertia.js no frontend, eliminando a complexidade de gerenciar APIs REST separadas sem necessidade. O banco de dados padrão é o PostgreSQL 18, configurado para utilizar UUIDs como chaves primárias, garantindo maior segurança e escalabilidade.

Na arquitetura de código, adotamos estritamente o Service Pattern para promover os princípios SOLID e evitar controladores inchados. Os Controllers são mantidos magros, responsáveis apenas por receber a requisição HTTP, validar os dados de entrada (utilizando FormRequests) e devolver a resposta. Toda a regra de negócio e inteligência da aplicação reside na camada de Services (app/Services), encapsulada em classes reutilizáveis e testáveis. Os Models do Eloquent devem permanecer leves, focados apenas na definição de esquema, relacionamentos e Scopes de consulta. Mantemos a estrutura de Repositories (app/Repositories) presente mas opcional, reservada exclusivamente para consultas complexas ou relatórios pesados, evitando a superengenharia de abstrair o Eloquent para operações CRUD triviais. Além disso, o kit já traz Middlewares pré-configurados para integração com o Inertia e validação de permissões baseadas em funções (RBAC), consumindo os tokens do ArraiAuth.

A infraestrutura é totalmente containerizada via Docker, utilizando uma estratégia de orquestração inteligente. O arquivo docker-compose.yml define a base comum, enquanto arquivos de override (dev e prod) ajustam o ambiente automaticamente. Em desenvolvimento, o kit fornece ferramentas auxiliares como Mailpit (para testes seguros de e-mail) e um servidor de documentação local. Em produção, esses serviços são suprimidos para economia de recursos. Cada projeto instanciado a partir deste kit possui seu próprio container Redis e seu próprio painel Laravel Horizon para gerenciamento de filas assíncronas, garantindo isolamento total: se um sistema falhar por sobrecarga, ele não impacta o desempenho dos vizinhos no servidor.

Para resolver os problemas históricos com geração de documentos, o kit inclui o serviço Gotenberg, uma API baseada em Docker que utiliza o motor do Chromium para renderizar PDFs. Isso permite criar documentos utilizando HTML e CSS modernos (Tailwind), além de fornecer ferramentas nativas para fusão (merge) de anexos e correção de versões de PDF, eliminando a dependência de bibliotecas legadas como mpdf. Este serviço vem configurado por padrão, mas pode ser desativado no docker-compose caso o módulo específico não necessite de geração de documentos, economizando memória RAM.

A segurança e integridade dos dados são prioridade. Por isso, o kit incorpora nativamente o pacote `spatie/laravel-backup` juntamente com o driver para Google Drive. O sistema vem configurado para executar rotinas automáticas de backup (dump do banco de dados e arquivos) diariamente, enviando os arquivos compactados diretamente para o drive institucional, garantindo uma estratégia de recuperação de desastres robusta sem necessidade de scripts externos.

O frontend já inclui a biblioteca de componentes Shadcn/UI pré-configurada com Tailwind CSS, acelerando a construção de interfaces visuais padronizadas. A autenticação é nativamente integrada ao ArraiAuth (nosso provedor SSO) via Laravel Socialite. Por fim, o projeto traz ferramentas de qualidade de código obrigatórias (Laravel Pint para formatação e Larastan para análise estática), garantindo que todo código entregue siga as mesmas diretrizes de estilo e segurança.
